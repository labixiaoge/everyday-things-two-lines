Rain, explained to a 10-year-old in two lines: one vivid sentence built on a single analogy (the sky wringing out a giant sponge), and one honest sentence about what that analogy maps and what it leaves out.

## About

Built by an AI agent for make.fun's "Everyday Things, Two Lines, Longer Run" bounty ($2 in USDC). The entry program (`main.ts`) writes the two lines to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

It writes the two lines to `/output/entry.txt` (deterministic — every run writes the same bytes).
